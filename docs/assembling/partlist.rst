Bauteilliste
============

Die nachfolgende Bauteilliste bezieht sich auf den Zusammenbau mit einer fertig bestückten und ggf. auch programmierten Platine. Sollen Sie die Bestückung der Platine selber vornehmen wollen, so finden Sie im GitLab Repository eine Stückliste zu den Elektronikbauteilen. Alternativ können Sie die `interaktive Bauteilliste`_ verwenden die sich hervorragend für eine manuelle Bestückung der Platine eignet.

.. _interaktive Bauteilliste: https://open-boat-projects.org/wp-content/uploads/2022/09/ibom_yachta.html

Die in der Bauteilliste aufgeführten Bezugsquellen können u.U. nicht mehr aktuell sein. Suchen Sie dann am besten im Internet nach alternativen Bezugsmöglichkeiten.
